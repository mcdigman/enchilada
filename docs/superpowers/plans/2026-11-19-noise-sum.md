**Goal:** Every block is registered as a signal block or a noise block (`wheel.add(block, role="signal" | "noise")`); `Wheel` keeps a persistent sum of the noise blocks' covariances exactly as it keeps a sum of the signal blocks' templates, hands a signal block the whole sum and a noise block the sum over the *other* noise blocks, and refuses a block that publishes what its role forbids; `Wheel(initial_covariance=...)` and `NoiseOverwrittenWarning` go, `FixedNoiseBlock` and `Covariance.__add__` arrive, and every test, example, notebook and document follows.

**Architecture:** The signal-sum tree becomes a generic persistent sum tree (`src/enchilada/_sum_tree.py`) with two thin wrappers, `SignalSum` (unchanged API) and `NoiseSum` (leaves are `Covariance | None`, combined with `Covariance.__add__`). `Wheel` records a role per block, keeps `_noise_sum` and the grid of the first noise publication, builds each block's inputs by role and validates each adoption by role; everything else PR #9 settled about `initial_sample` stays. The primitives land first with the suite green (Task 1); the core lands second with its own inverted tests (Task 2, the suite is red until the migrations finish); five independent migrations run in parallel (Tasks 3–7); the documentation task closes with full gates (Task 8).

**Tech Stack:** Python 3.12+, NumPy, the existing `Wheel`/`BlockState`/`Covariance`/`transform` machinery; pytest, ruff, mypy; notebooks edited as JSON by cell id (`demo.ipynb` by text substitution).

**User decisions (already made, 2026-11-19):**
- A noise block receives the sum over the *other* noise blocks (None when it is alone); its own last publication stays on `current_block_state.covariance`. A signal block receives the sum over all noise blocks.
- `wheel.add(block, *, role=...)` with `role` a required keyword, `"signal"` or `"noise"`, strict: a signal block may not publish a covariance, a noise block may not publish a template and must publish a covariance on every call. A joint model is split into two blocks.
- The first noise publication fixes the grid of the sum; a later noise block on another grid is refused at `add`, before its `initial_sample` runs.
- `Wheel(initial_covariance=...)` is removed: "The initial covariance needs to come from the blocks' initial_sample()". A known noise model is a `FixedNoiseBlock`.
- The sum is a persistent `NoiseSum` mirroring `SignalSum`.
- A new small example, `examples/noise_floor.py`, demonstrates two noise blocks; the tutorial's conjugate noise block stays single-noise and says so.

**Refinements of the spec recorded here (not open questions; reviewers compare against these):**
- `random_seed` stays keyword-only (`Wheel(observed_data, *, random_seed=None)`), as today, so the old positional `Wheel(observed, covariance)` fails with a clear `TypeError` about positional arguments instead of deep inside `default_rng`.
- The covariance handed to a block is `deepcopy(total)`, not `Covariance.copy(total)`: every leaf passed `Covariance.copy` at adoption and every sum was built by `Covariance.__add__` through the validating constructor, so the hand-over restores a validated object read-only without a second Cholesky, exactly as today's `_block_inputs` does.
- The new behaviour tests (`TestRoles`, `TestNoiseSum`, `TestRemovedApi`) live in a new file `tests/test_noise_sum.py` instead of `tests/test_wheel.py`: `tests/test_wheel.py` imports `NoiseOverwrittenWarning` at module level and cannot be collected between Task 2 and Task 3, and the core's behaviour must be verified in the task that builds it.
- `Role = Literal["signal", "noise"]` is defined in `enchilada.wheel` and used by `Wheel.add` and `check_block`; it is not exported from the package.
- `_SumTree.excluding(index)` returns the total for an index at or beyond the tree's capacity (a slot that was never filled excludes nothing).

"""The persistent sum trees behind Wheel's residuals and its noise sum."""

import numpy as np
import pytest

from conftest import white_covariance
from enchilada import Covariance, L1Data
from enchilada._sum_tree import NoiseSum, SignalSum


def data():
    return L1Data(
        {"A": np.zeros(8), "E": np.zeros(8)},
        sample_rate_hz=1.0,
        tdi_generation="2.0",
        physical_observable="strain",
    )


class SignalLeaves:
    """Templates: dicts of channel arrays; the sum is read on channel A."""

    tree = SignalSum
    add = staticmethod(SignalSum.with_signal)

    @staticmethod
    def leaf(level):
        return {"A": np.full(8, level), "E": np.full(8, 2 * level)}

    @staticmethod
    def value(total):
        return None if total is None else float(total["A"][0])


class NoiseLeaves:
    """Covariances: white noise of `level` on one grid; the sum is read on A."""

    tree = NoiseSum
    add = staticmethod(NoiseSum.with_covariance)

    @staticmethod
    def leaf(level):
        return white_covariance(data(), level)

    @staticmethod
    def value(total):
        return None if total is None else float(total.A[0])


@pytest.fixture(params=[SignalLeaves, NoiseLeaves], ids=["signal", "noise"])
def leaves(request):
    return request.param


def test_the_empty_tree_sums_to_none(leaves):
    tree = leaves.tree()
    assert tree.total is None
    assert tree.excluding(0) is None
    assert tree.excluding(7) is None


def test_one_leaf_is_its_own_total_and_excluding_it_leaves_nothing(leaves):
    tree = leaves.add(leaves.tree(), 0, leaves.leaf(1.0))
    assert leaves.value(tree.total) == 1.0
    assert tree.excluding(0) is None
    # A slot beyond the capacity was never filled, so excluding it drops nothing.
    assert leaves.value(tree.excluding(1)) == 1.0


def test_three_leaves_sum_and_each_exclusion_drops_one(leaves):
    tree = leaves.tree()
    for index, level in enumerate((1.0, 2.0, 4.0)):
        tree = leaves.add(tree, index, leaves.leaf(level))
    assert leaves.value(tree.total) == 7.0
    assert leaves.value(tree.excluding(0)) == 6.0
    assert leaves.value(tree.excluding(1)) == 5.0
    assert leaves.value(tree.excluding(2)) == 3.0
    assert leaves.value(tree.excluding(3)) == 7.0  # capacity 4, slot 3 empty


def test_replacing_a_slot_and_withdrawing_it(leaves):
    tree = leaves.tree()
    for index, level in enumerate((1.0, 2.0, 4.0)):
        tree = leaves.add(tree, index, leaves.leaf(level))
    replaced = leaves.add(tree, 1, leaves.leaf(10.0))
    assert leaves.value(replaced.total) == 15.0
    assert leaves.value(replaced.excluding(1)) == 5.0
    withdrawn = leaves.add(replaced, 1, None)
    assert leaves.value(withdrawn.total) == 5.0
    assert leaves.value(withdrawn.excluding(1)) == 5.0
    assert leaves.value(withdrawn.excluding(0)) == 4.0


def test_a_discarded_candidate_leaves_the_accepted_tree_unchanged(leaves):
    accepted = leaves.add(leaves.tree(), 0, leaves.leaf(1.0))
    accepted = leaves.add(accepted, 1, leaves.leaf(2.0))
    candidate = leaves.add(accepted, 1, leaves.leaf(100.0))
    candidate = leaves.add(candidate, 5, leaves.leaf(1000.0))  # grows the candidate
    assert leaves.value(candidate.total) == 1101.0
    assert leaves.value(candidate.excluding(5)) == 101.0
    assert leaves.value(accepted.total) == 3.0
    assert leaves.value(accepted.excluding(0)) == 2.0
    assert leaves.value(accepted.excluding(1)) == 1.0
    assert leaves.value(accepted.excluding(5)) == 3.0


def test_sparse_slots_skip_the_empty_leaves(leaves):
    tree = leaves.add(leaves.tree(), 6, leaves.leaf(3.0))
    assert leaves.value(tree.total) == 3.0
    assert tree.excluding(6) is None
    assert leaves.value(tree.excluding(0)) == 3.0
    assert leaves.value(tree.excluding(7)) == 3.0


def test_signal_sum_promotes_float32_leaves_to_float64():
    tree = SignalSum().with_signal(0, {"A": np.full(4, 1e8, np.float32)})
    tree = tree.with_signal(1, {"A": np.full(4, 1.0, np.float32)})
    tree = tree.with_signal(2, {"A": np.full(4, -1e8, np.float32)})
    assert tree.total["A"].dtype == np.float64
    np.testing.assert_array_equal(tree.total["A"], 1.0)


def test_noise_sum_totals_are_validated_read_only_covariances():
    tree = NoiseSum().with_covariance(0, white_covariance(data(), 1.0))
    tree = tree.with_covariance(1, white_covariance(data(), 2.0))
    assert type(tree.total) is Covariance
    assert not tree.total.blocks.flags.writeable
    np.testing.assert_array_equal(tree.total.E, 3.0)
    np.testing.assert_array_equal(tree.excluding(0).E, 2.0)
    assert tree.total.grid == data().grid

    def test_sums_variances_and_cross_terms_on_one_grid(self):
        data = time_data()
        left = Covariance.like(
            data, {"A": np.full(8, 1.0), "E": np.full(8, 2.0), "AE": np.full(8, 0.5)}

        assert total.grid == data.grid
        assert total.channel_names == ("A", "E")
        np.testing.assert_array_equal(total.A, 4.0)
        np.testing.assert_array_equal(total.E, 6.0)
        np.testing.assert_array_equal(total.AE, 0.5)
        np.testing.assert_array_equal(total.EA, 0.5)
        assert not total.blocks.flags.writeable
        assert not np.shares_memory(total.blocks, left.blocks)
        assert not np.shares_memory(total.blocks, right.blocks)
        np.testing.assert_array_equal(left.A, 1.0)  # the operands are untouched
        np.testing.assert_array_equal(right.AE, 0.0)

    def test_addition_is_commutative_and_promotes_to_complex(self):
        data = frequency_data()  # 8 samples: 5 bins, DC and Nyquist real
        real = Covariance.like(data, {"A": np.full(5, 1.0), "E": np.full(5, 1.0)})
        cross = np.full(5, 0.25 + 0.1j)
        cross[0] = cross[-1] = 0.25
        with_cross = Covariance.like(
            data, {"A": np.full(5, 2.0), "E": np.full(5, 2.0), "AE": cross}
        )
        total = real + with_cross
        assert total.blocks.dtype == np.complex128
        np.testing.assert_array_equal(total.A, 3.0)
        np.testing.assert_array_equal(total.E, 3.0)
        np.testing.assert_array_equal(total.AE, cross)
        np.testing.assert_array_equal(total.EA, np.conj(cross))
        np.testing.assert_array_equal((with_cross + real).blocks, total.blocks)

    def test_the_sum_passes_the_constructor_checks(self):
        # Each term is positive definite; the sum goes through the same Cholesky.
        data = time_data()
        tight = Covariance.like(
            data, {"A": np.ones(8), "E": np.ones(8), "AE": np.full(8, 0.99)}
        )
        total = tight + tight
        np.testing.assert_array_equal(total.A, 2.0)
        np.testing.assert_array_equal(total.AE, 1.98)

    def test_grids_must_match(self):
        data = time_data()

        with pytest.raises(ValueError, match="does not add across grids") as info:
            left + white_covariance(data.to_frequency(), 1.0)
        assert "data_domain='time'" in str(info.value)
        assert "data_domain='frequency'" in str(info.value)
        with pytest.raises(ValueError, match="does not add across grids"):

"""FixedNoiseBlock publishes one configured covariance on every call."""

from copy import deepcopy

import numpy as np
import pytest

from conftest import white_covariance
from enchilada import Block, BlockState, Covariance
from enchilada.fixed_noise import FixedNoiseBlock


def test_it_is_a_block_publishing_its_covariance_from_both_methods(observed, rng):
    block = FixedNoiseBlock("floor", white_covariance(observed, 2.0))
    assert isinstance(block, Block)
    assert block.name == "floor"
    start = block.initial_sample(observed, None, rng=rng)
    later = block.sample(observed, None, BlockState(), rng=rng)
    for published in (start, later):
        assert isinstance(published, BlockState)
        assert published.template is None
        assert published.parameters == {}
        assert type(published.covariance) is Covariance
        published.covariance.check_compatible(observed)
        np.testing.assert_array_equal(published.covariance.A, 2.0)
        assert not published.covariance.blocks.flags.writeable
    assert start.covariance is not later.covariance
    assert not np.shares_memory(start.covariance.blocks, later.covariance.blocks)


def test_inputs_and_rng_are_ignored(observed):
    block = FixedNoiseBlock("floor", white_covariance(observed, 2.0))
    rng = np.random.default_rng(0)
    before = rng.bit_generator.state
    other = white_covariance(observed, 5.0)
    published = block.sample(observed, other, BlockState(covariance=other), rng=rng)
    np.testing.assert_array_equal(published.covariance.A, 2.0)
    assert rng.bit_generator.state == before
    assert block.initial_sample(observed, other, rng=rng).covariance.A[0] == 2.0
    assert rng.bit_generator.state == before


def test_the_configured_covariance_is_an_independent_copy(observed, rng):
    covariance = white_covariance(observed, 2.0)
    block = FixedNoiseBlock("floor", covariance)
    covariance.blocks.setflags(write=True)
    covariance.A[:] = 99.0
    published = block.initial_sample(observed, None, rng=rng)
    np.testing.assert_array_equal(published.covariance.A, 2.0)
    published.covariance.blocks.setflags(write=True)
    published.covariance.A[:] = 7.0
    again = block.sample(observed, None, BlockState(), rng=rng)
    np.testing.assert_array_equal(again.covariance.A, 2.0)


def test_the_configured_covariance_is_revalidated_through_the_base_class(observed):
    class Unchecked(Covariance):
        def copy(self):
            return self

    valid = white_covariance(observed, 1.0)
    unchecked = Unchecked(
        valid.blocks, channel_names=valid.channel_names, grid=valid.grid
    )
    unchecked.blocks.setflags(write=True)
    unchecked.A[:] = -1.0  # no longer a covariance
    with pytest.raises(ValueError, match="positive"):
        FixedNoiseBlock("broken", unchecked)
    unchecked.A[:] = 1.0
    block = FixedNoiseBlock("plain", unchecked)
    assert type(block.initial_sample(observed, None, rng=None).covariance) is Covariance


def test_anything_but_a_covariance_is_refused():
    with pytest.raises(TypeError, match="must be a Covariance, got dict"):
        FixedNoiseBlock("floor", {"A": np.ones(4)})
    with pytest.raises(TypeError, match="must be a Covariance, got NoneType"):
        FixedNoiseBlock("floor", None)


def test_deepcopy_keeps_the_covariance(observed, rng):
    block = FixedNoiseBlock("floor", white_covariance(observed, 2.0))
    clone = deepcopy(block)
    assert clone.name == "floor"
    published = clone.initial_sample(observed, None, rng=rng)
    np.testing.assert_array_equal(published.covariance.A, 2.0)

"""Persistent pairwise sums of internally owned, validated block publications.

Replacing a leaf copies only its path to the root. An uncommitted candidate can
therefore be discarded without changing accepted state. Leaves are never
mutated here, and an absent publication needs no zero element. Wheel keeps both
trees private: `SignalSum` adds templates and `NoiseSum` adds covariances.
"""

from collections.abc import Callable
from dataclasses import dataclass, field, replace
from typing import Generic, TypeVar

import numpy as np

from enchilada.covariance import Covariance

Signal = dict[str, np.ndarray] | None
Noise = Covariance | None
T = TypeVar("T")


def _combine_signals(left: Signal, right: Signal) -> Signal:
    if left is None:
        return right
    if right is None:
        return left
    # Do not round a subtree of float32 signals before it meets a float64
    # observation or another wider signal elsewhere in the tree.
    with np.errstate(over="ignore", invalid="ignore"):
        return {
            name: np.add(
                values,
                right[name],
                dtype=np.result_type(values, right[name], np.float64),
            )
            for name, values in left.items()
        }


def _combine_covariances(left: Noise, right: Noise) -> Noise:
    if left is None:
        return right
    if right is None:
        return left
    return left + right


@dataclass(frozen=True, eq=False)
class _Node(Generic[T]):
    total: T
    left: "_Node[T] | None"
    right: "_Node[T] | None"


@dataclass(frozen=True, eq=False)
class _SumTree(Generic[T]):
    """A persistent aggregate indexed by nonnegative block registration positions.

    `combine(left, right)` adds two partial sums and `empty` is the sum of
    nothing. Both trees use None for an absent leaf and let `combine` skip it.
    """

    combine: Callable[[T, T], T]
    empty: T
    _root: _Node[T] | None = None
    _capacity: int = 1

    def _total(self, node: _Node[T] | None) -> T:
        return self.empty if node is None else node.total

    @property
    def total(self) -> T:
        return self._total(self._root)

    def with_leaf(self, index: int, leaf: T) -> "_SumTree[T]":
        root, capacity = self._root, self._capacity
        while index >= capacity:
            root = _Node(self._total(root), root, None)
            capacity *= 2
        return replace(
            self, _root=self._replace(root, index, capacity, leaf), _capacity=capacity
        )

    def _replace(
        self, node: _Node[T] | None, index: int, capacity: int, leaf: T
    ) -> _Node[T]:
        if capacity == 1:
            return _Node(leaf, None, None)
        midpoint = capacity // 2
        left = None if node is None else node.left
        right = None if node is None else node.right
        if index < midpoint:
            left = self._replace(left, index, midpoint, leaf)
        else:
            right = self._replace(right, index - midpoint, midpoint, leaf)
        return _Node(self.combine(self._total(left), self._total(right)), left, right)

    def excluding(self, index: int) -> T:
        if index >= self._capacity:
            return self.total  # that slot was never filled
        return self._excluding(self._root, index, self._capacity)

    def _excluding(self, node: _Node[T] | None, index: int, capacity: int) -> T:
        if node is None or capacity == 1:
            return self.empty
        midpoint = capacity // 2
        if index < midpoint:
            return self.combine(
                self._excluding(node.left, index, midpoint), self._total(node.right)
            )
        return self.combine(
            self._total(node.left),
            self._excluding(node.right, index - midpoint, midpoint),
        )


@dataclass(frozen=True, eq=False)
class SignalSum:
    """A private aggregate of block templates by registration position."""

    _tree: _SumTree[Signal] = field(
        default_factory=lambda: _SumTree(_combine_signals, None)
    )

    @property
    def total(self) -> Signal:
        return self._tree.total

    def with_signal(self, index: int, signal: Signal) -> "SignalSum":
        return SignalSum(self._tree.with_leaf(index, signal))

    def excluding(self, index: int) -> Signal:
        return self._tree.excluding(index)


@dataclass(frozen=True, eq=False)
class NoiseSum:
    """A private aggregate of noise blocks' covariances by registration position.

    Every leaf is a validated Covariance on one grid with one channel order;
    Wheel guarantees that before storing one, so `Covariance.__add__` never
    refuses a sum here.
    """

    _tree: _SumTree[Noise] = field(
        default_factory=lambda: _SumTree(_combine_covariances, None)
    )

    @property
    def total(self) -> Noise:
        return self._tree.total

    def with_covariance(self, index: int, covariance: Noise) -> "NoiseSum":
        return NoiseSum(self._tree.with_leaf(index, covariance))

    def excluding(self, index: int) -> Noise:
        return self._tree.excluding(index)

    def __add__(self, other: object) -> "Covariance":
        """The elementwise sum of two covariances on one grid: a new Covariance.

        Both operands must carry the same grid and channel order. The result is
        validated like any construction, so a sum of positive-definite terms is
        checked positive definite again rather than assumed. This is how a noise
        block forms the other blocks' sum plus its own model for its likelihood.
        """

            return NotImplemented

            raise ValueError(

                f"cannot add a covariance with channel_names {other.channel_names} "
                f"to one with channel_names {self.channel_names}"
            )
        return Covariance(
            self.blocks + other.blocks, channel_names=self.channel_names, grid=self.grid
        )

"""A noise block that publishes one fixed covariance on every call."""

from copy import deepcopy

import numpy as np

from enchilada.block_state import BlockState
from enchilada.covariance import Covariance
from enchilada.data import L1Data


class FixedNoiseBlock:
    """Publish a known covariance as a noise block; nothing is sampled.

    ``wheel.add(FixedNoiseBlock("floor", covariance), role="noise")`` adds
    ``covariance`` to the campaign's noise sum at registration and republishes
    it every cycle, so signal blocks receive it and other noise blocks add
    their own models on top. The covariance must be on the grid the block is
    registered on (``data_domain`` at ``add``), like any noise publication.
    ``initial_sample`` and ``sample`` ignore their inputs and draw nothing.
    The constructor keeps an independent, revalidated copy.
    """

    def __init__(self, name: str, covariance: Covariance) -> None:
        if not isinstance(covariance, Covariance):
            raise TypeError(
                "FixedNoiseBlock covariance must be a Covariance, got "
                f"{type(covariance).__name__}"
            )
        self.name = name
        # Unbound call: copy without trusting a subclass's overridden methods.
        self._covariance = Covariance.copy(covariance)

    def _publish(self) -> BlockState:
        # deepcopy restores a validated Covariance read-only without revalidating.
        return BlockState(covariance=deepcopy(self._covariance))

    def initial_sample(
        self,
        conditional_residual: L1Data,
        covariance: Covariance | None,
        *,
        rng: np.random.Generator,
    ) -> BlockState:
        """Publish the configured covariance; the inputs and ``rng`` are unused."""
        return self._publish()

    def sample(
        self,
        conditional_residual: L1Data,
        covariance: Covariance | None,
        current_block_state: BlockState,
        *,
        rng: np.random.Generator,
    ) -> BlockState:
        """Publish the configured covariance again; the inputs and ``rng`` are unused."""
        return self._publish()

    samples normally until `method` is called.

    def __init__(self, name, seen):

from collections.abc import Callable
from copy import deepcopy
from dataclasses import replace
from typing import Literal

import numpy as np

from enchilada._sum_tree import NoiseSum, Signal, SignalSum
from enchilada.block import Block

Role = Literal["signal", "noise"]
ROLES: tuple[Role, ...] = ("signal", "noise")


class Wheel:
    """Run blocks while owning their accepted physical estimates and shared data.

    The pristine observation is copied at construction. A second L1Data stores
    the full working residual, rebuilt after every accepted update. For block i,
    the input is d - sum(j != i, T_j); the block's own signal remains in its input.
    An absent TDI signal contributes zero, including when a block previously
    returned a signal. Ledger holds complete BlockState snapshots. Public data and
    covariance access returns copies. The ledger property returns a live handle;
    indexing and snapshot() copy its contents. Treat orbit resources as immutable.

    Every block is registered as a signal block or a noise block. Signal blocks
    publish templates, which Wheel sums into the residuals; noise blocks publish
    covariances, which Wheel sums into the campaign covariance. A signal block
    receives the sum over every noise block (None until one has published); a
    noise block receives the sum over the other noise blocks (None when it is
    alone) and its own last publication on current_block_state.covariance. A
    noise block must return a covariance on every call and may not return a
    template; a signal block may not return a covariance.

    Registration calls the block's `initial_sample` with the residual of the
    blocks registered so far on the block's grid, the covariance its role
    receives, and the campaign RNG, then adopts the returned state like a
    `sample` return. Each cycle calls sample with those inputs and the
    current_block_state from the ledger. Sampling receives the supplied RNG and
    independent input snapshots. Failed calls/validation/copying leave the
    ledger, both sums and the Wheel RNG unchanged. Blocks own their sampler
    state and diagnostics; Wheel does not roll back changes to those internals.
    Use separate block instances for separate campaigns. Earlier successful
    updates in a failed cycle remain committed. Exceptions in on_cycle_complete
    occur after that entire cycle has committed.

    Signals are stored on the observation grid. The covariance sum lives on the
    grid of the first noise publication: a noise block registered on another
    grid is refused at add, and a signal block on another grid is refused at
    add or run, each with ValueError naming both grids. A block registered with
    data_domain has its inputs and returned signal translated; a covariance is
    never translated.
    """

    def __init__(
        self,
        observed_data: L1Data,
        *,
        random_seed: int | None = None,
    ) -> None:
        """Initialize a campaign from observations.

        Args:
            observed_data: L1 observations and shared run settings. The Wheel
                makes independent pristine and working copies.
            random_seed: Seed for the campaign's NumPy generator. None requests
                nondeterministic initialization.

        The campaign has no covariance until a noise block publishes one at
        registration; a known noise model is a FixedNoiseBlock.
        """
        if not isinstance(observed_data, L1Data):
            raise TypeError("observed_data must be L1Data")
        for ch in observed_data.channel_names:
            if not np.isfinite(observed_data.channel_data[ch]).all():
                raise ValueError(
                    f"observed_data.channel_data[{ch!r}] has non-finite samples; "
                    "enchilada has no data-quality mask for gaps; "
                    "fill or trim them first"
                )
        self._observed_data = self._copy_data(observed_data)
        self._working_residual = self._copy_data(observed_data)
        self._ledger = Ledger()
        self._blocks: list[tuple[str, Block]] = []
        self._block_indices: dict[str, int] = {}
        self._block_domains: dict[str, Grid] = {}
        self._roles: dict[str, Role] = {}
        self._signal_sum = SignalSum()
        self._noise_sum = NoiseSum()
        self._covariance_grid: Grid | None = None
        self._rng = np.random.default_rng(random_seed)

    @staticmethod
    def _copy_data(data_to_copy: L1Data) -> L1Data:
        """Copy channel arrays, preserving immutable orbit data."""
        if data_to_copy.data_domain == "wdm":
            data_to_copy._validate_channel_data_lengths()
        return replace(
            data_to_copy,
            channel_data={
                ch: arr.copy() for ch, arr in data_to_copy.channel_data.items()
            },
        )

    @property
    def observed_data(self) -> L1Data:
        """A defensive copy of the pristine observation."""
        return self._copy_data(self._observed_data)

    @property
    def working_residual(self) -> L1Data:
        """A defensive copy of the current full residual."""
        return self._copy_data(self._working_residual)

    @property
    def covariance(self) -> Covariance | None:
        """The sum over every noise block's covariance, as an independent copy.

        None until a noise block has published. The sum lives on the grid of
        the first noise publication.
        """
        total = self._noise_sum.total
        if total is None:
            return None
        # Leaves passed Covariance.copy at adoption and sums were built by
        # Covariance.__add__ through the constructor: restore unvalidated.
        return deepcopy(total)

    @property
    def ledger(self) -> Ledger:
        """Live state store; indexing copies entries, snapshot() copies all entries."""
        return self._ledger

    def add(
        self,
        block_to_register: Block,
        *,
        role: Role,
        data_domain: str | None = None,
        num_frequency_divisions: int | None = None,
        num_time_divisions: int | None = None,
    ) -> None:
        """Register a block under a role and adopt the start its initial_sample returns.

        role is "signal" or "noise" and is checked before anything else. A
        signal block publishes a template and never a covariance; a noise
        block publishes a covariance on every call and never a template.
        block_to_register must have a unique name and implement initial_sample
        and sample. Failed registration leaves the campaign unchanged: an
        exception from initial_sample, a return that is not a BlockState, an
        off-grid or non-finite template, a field the role forbids or lacks, a
        covariance on another grid than the block's, or a state that cannot be
        deep-copied leaves the ledger, the block list, the residual, both sums
        and the Wheel RNG as they were.

        initial_sample receives the current working residual (the observations
        minus the adopted starts of every block registered so far) on this
        block's grid, the covariance its role receives (the sum over every
        noise block for a signal block, the sum over the other noise blocks for
        a noise block; None while that sum is empty) and a copy of the campaign
        RNG that is committed with the state. Blocks therefore start in
        registration order: register the noise blocks before the blocks whose
        starts need their covariance. The returned state is validated and
        adopted exactly like a sample return: its template must be on this
        block's grid, and Wheel translates it to the observation grid for
        storage. A block that must start at a chosen point takes that point in
        its constructor and returns it from initial_sample.

        data_domain selects time, frequency or wdm for this block's residual,
        current state and published covariance. None keeps the observation grid.
        For WDM, specify either division count; the other follows from the
        observation length. Both counts must be even. An existing observation
        WDM grid is reused if neither count is supplied. The covariance sum
        lives on the grid of the first noise publication; a noise block on
        another grid is refused here, before initial_sample is called, and so
        is a signal block once a covariance has been published.
        """
        if role not in ROLES:
            raise ValueError(f"role must be 'signal' or 'noise', got {role!r}")
        observed = self._observed_data
        if data_domain is None:
            if num_frequency_divisions is not None or num_time_divisions is not None:
                raise ValueError("WDM division counts require data_domain='wdm'")
            block_grid = observed.grid
        else:
            block_grid = Grid(
                data_domain,
                observed.num_time_samples,
                observed.sample_rate_hz,
                _target_grid(
                    data_domain,
                    observed.num_time_samples,
                    observed.wdm_grid,
                    num_frequency_divisions,
                    num_time_divisions,
                ),
            )
        block_name = getattr(block_to_register, "name", None)
        if not isinstance(block_name, str) or not block_name:
            raise ValueError(
                f"block name must be a non-empty string, got {block_name!r}"
            )
        if block_name in self._ledger:
            raise ValueError(f"block name {block_name!r} already registered")
        if not callable(getattr(block_to_register, "sample", None)):
            raise TypeError(
                f"block {block_name!r} does not implement sample; "
                "a Block needs name, initial_sample(conditional_residual, "
                "covariance, *, rng) and sample(conditional_residual, "
                "covariance, current_block_state, *, rng)."
            )
        if not callable(getattr(block_to_register, "initial_sample", None)):
            raise TypeError(
                f"block {block_name!r} does not implement initial_sample; "
                "a Block needs name, initial_sample(conditional_residual, "
                "covariance, *, rng) and sample(conditional_residual, "
                "covariance, current_block_state, *, rng)."
            )
        conditional_residual, covariance = self._block_inputs(
            block_name, block_grid, role=role, registered=False
        )
        candidate_rng = deepcopy(self._rng)
        new_block_state: object = block_to_register.initial_sample(
            conditional_residual=conditional_residual,
            covariance=covariance,
            rng=candidate_rng,
        )
        if block_grid != observed.grid:
            new_block_state = self._canonical_state(
                new_block_state, conditional_residual
            )
        self._adopt(
            block_name,
            new_block_state,
            "initial_sample",
            candidate_rng,
            role=role,
            block_to_register=block_to_register,
            block_grid=block_grid,
        )

    def _block_inputs(
        self, block_name: str, block_grid: Grid, *, role: Role, registered: bool
    ) -> tuple[L1Data, Covariance | None]:
        """Conditional residual on the block's grid, and the covariance its role gets.

        A registered block's residual leaves its own signal in; a block being
        registered has no signal yet, so it receives the working residual. A
        signal block receives the sum over every noise block; a noise block
        receives the sum over the other noise blocks, which is the whole sum
        while it is being registered because its own slot does not exist yet.
        """
        if self._covariance_grid is not None and self._covariance_grid != block_grid:
            if role == "noise":
                raise ValueError(
                    f"block {block_name!r} is registered on grid {block_grid} but "
                    f"the campaign covariance is on grid {self._covariance_grid}; "
                    "a covariance does not add across grids"
                )
            raise ValueError(
                f"block {block_name!r} is registered on grid {block_grid} but the "
                f"current covariance is on grid {self._covariance_grid}; a "
                "covariance does not translate between grids. Register the block "
                "on the covariance's grid, or have the noise block publish on the "
                "block's grid."
            )
        conditional_residual = (
            self.residual(exclude_block_name=block_name)
            if registered
            else self.working_residual
        )
        if block_grid != self._observed_data.grid:
            conditional_residual = transform(
                conditional_residual,
                block_grid.data_domain,
                num_frequency_divisions=self._frequency_divisions(block_grid),
            )
        if role == "noise" and registered:
            total = self._noise_sum.excluding(self._block_indices[block_name])
        else:
            total = self._noise_sum.total
        # Stored covariances were validated when published or summed: restore
        # an independent read-only copy without revalidating.
        covariance = None if total is None else deepcopy(total)
        return conditional_residual, covariance

    @staticmethod
    def _frequency_divisions(grid: Grid) -> int | None:
        if grid.wdm_grid is None:
            return None
        return grid.wdm_grid.num_frequency_divisions

    def _canonical_state(self, state: object, source_reference: L1Data) -> object:
        if not isinstance(state, BlockState):
            return state  # _adopt supplies the block/method-specific error.
        return transform(
            state,
            self._observed_data.data_domain,
            reference_data=source_reference,
            num_frequency_divisions=self._frequency_divisions(self._observed_data.grid),
        )

    def run(
        self,
        num_cycles: int,
        on_cycle_complete: Callable[[int, "Wheel"], None] | None = None,
    ) -> None:
        """Visit blocks in registration order; notify after each complete cycle.

        Cycle indices are local to this invocation. Multiple run calls continue
        the accepted ledger and RNG; run(0) does nothing.

        Args:
            num_cycles: Non-negative number of complete Gibbs cycles to attempt.
            on_cycle_complete: Optional callback receiving (cycle_index, wheel)
                after every block in a cycle has returned an accepted state.
                Indices start at zero for each run call. Partial cycles do not
                invoke the callback.
        """
        if (
            not isinstance(num_cycles, (int, np.integer))
            or isinstance(num_cycles, bool)
            or num_cycles < 0
        ):
            raise ValueError(
                f"num_cycles must be a non-negative integer, got {num_cycles!r}"
            )
        for cycle_index in range(num_cycles):
            for block_name, block in self._blocks:
                candidate_rng = deepcopy(self._rng)
                block_grid = self._block_domains[block_name]
                role = self._roles[block_name]
                conditional_residual, covariance = self._block_inputs(
                    block_name, block_grid, role=role, registered=True
                )
                current_block_state = self._ledger[block_name]
                translated = block_grid != self._observed_data.grid
                if translated:
                    current_block_state = transform(
                        current_block_state,
                        block_grid.data_domain,
                        reference_data=self._observed_data,
                        num_frequency_divisions=self._frequency_divisions(block_grid),
                    )
                new_block_state: object = block.sample(
                    conditional_residual=conditional_residual,
                    covariance=covariance,
                    current_block_state=current_block_state,
                    rng=candidate_rng,
                )
                if translated:
                    new_block_state = self._canonical_state(
                        new_block_state, conditional_residual
                    )
                self._adopt(
                    block_name,
                    new_block_state,
                    "sample",
                    candidate_rng,
                    role=role,
                    block_grid=block_grid,
                )
            if on_cycle_complete is not None:
                on_cycle_complete(cycle_index, self)

    def _form_residual(self, signal_sum: Signal) -> L1Data:
        """Subtract an aggregate signal from pristine observations."""
        channel_data = {}
        for ch, observed_channel_values in self._observed_data.channel_data.items():
            if signal_sum is None:
                residual_channel_values = observed_channel_values.copy()
            else:
                with np.errstate(over="ignore", invalid="ignore"):
                    residual_channel_values = observed_channel_values - signal_sum[ch]
            if not np.isfinite(residual_channel_values).all():
                raise ValueError(f"residual in channel {ch!r} became non-finite")
            channel_data[ch] = residual_channel_values
        return replace(self._observed_data, channel_data=channel_data)

    def residual(self, exclude_block_name: str | None = None) -> L1Data:
        """Return a copied full residual or a block's conditional residual.

        exclude_block_name identifies a registered block whose signal is left
        in the observations. None subtracts every block's signal.
        """
        if exclude_block_name is None:
            return self.working_residual
        self._require_block_name(exclude_block_name)
        return self._form_residual(
            self._signal_sum.excluding(self._block_indices[exclude_block_name])
        )

    def contribution(self, block_name: str) -> dict[str, np.ndarray]:
        """Copy the registered block's summed TDI signal.

        block_name must identify a registered block. An absent contribution
        returns fresh zero arrays on the observation grid.
        """
        self._require_block_name(block_name)
        signal = self._ledger._states_by_block_name[block_name].template
        if signal is None:
            return {
                ch: np.zeros_like(arr)
                for ch, arr in self._observed_data.channel_data.items()
            }
        return {ch: arr.copy() for ch, arr in signal.items()}

    def _require_block_name(self, block_name: str) -> None:
        if block_name not in self._ledger:
            raise ValueError(
                f"unknown block {block_name!r}; registered: {sorted(self._ledger)}"
            )

    def _adopt(
        self,
        block_name: str,
        new_block_state: object,
        source_method_name: str,
        candidate_rng: np.random.Generator,
        *,
        role: Role,
        block_to_register: Block | None = None,
        block_grid: Grid,
    ) -> None:
        """Validate a candidate state and RNG before committing campaign state.

        source_method_name names the block method whose return is being adopted,
        for diagnostics. role decides which fields the state may and must carry.
        block_to_register is supplied only when adopting a new block's initial state.
        block_grid is the grid the block is registered on; a published covariance
        must be on it.
        """
        if not isinstance(new_block_state, BlockState):
            raise TypeError(
                f"{block_name}.{source_method_name} must return a BlockState, got "
                f"{type(new_block_state).__name__}"
            )
        # Snapshot BEFORE validation so subsequent use only touches owned state.
        candidate_block_state = deepcopy(new_block_state)
        candidate_block_state.__post_init__()
        signal = candidate_block_state.template
        if signal is not None:
            check_on_grid(
                signal,
                channel_names=self._observed_data.channel_names,
                num_time_samples=self._observed_data.num_time_samples,
                data_domain=self._observed_data.data_domain,
                wdm_grid=self._observed_data.wdm_grid,
                context_label=f"{block_name}.{source_method_name} template",
            )
            for ch, arr in signal.items():
                if not np.isfinite(arr).all():
                    raise ValueError(
                        f"{block_name}.{source_method_name} returned non-finite "
                        f"samples in channel {ch!r}"
                    )
        block_index = (
            len(self._blocks)
            if block_to_register is not None
            else self._block_indices[block_name]
        )
        candidate_noise_sum = self._noise_sum
        candidate_covariance_grid = self._covariance_grid
        if role == "signal":
            if candidate_block_state.covariance is not None:
                raise ValueError(
                    f"{block_name}.{source_method_name} returned a covariance but "
                    f"{block_name!r} is registered as a signal block"
                )
        else:
            if signal is not None:
                raise ValueError(
                    f"{block_name}.{source_method_name} returned a template but "
                    f"{block_name!r} is registered as a noise block"
                )
            if candidate_block_state.covariance is None:
                raise ValueError(
                    f"{block_name}.{source_method_name} must return a covariance "
                    f"because {block_name!r} is registered as a noise block"
                )
            # Revalidate: callers can edit arrays inside a frozen dataclass.
            # Unbound call: copy without trusting a subclass's overridden methods.
            candidate_covariance = Covariance.copy(candidate_block_state.covariance)
            if candidate_covariance.channel_names != tuple(
                self._observed_data.channel_names
            ):
                raise ValueError(
                    f"{block_name}.{source_method_name} covariance channel_names "
                    f"{candidate_covariance.channel_names} do not match the data's "
                    f"{tuple(self._observed_data.channel_names)}"
                )
            if candidate_covariance.grid != block_grid:
                raise ValueError(
                    f"{block_name}.{source_method_name} covariance is on grid "
                    f"{candidate_covariance.grid} but the block is registered on "
                    f"grid {block_grid}; publish the covariance on the grid of the "
                    "data the block received"
                )
            candidate_block_state = replace(
                candidate_block_state, covariance=candidate_covariance
            )
            candidate_noise_sum = self._noise_sum.with_covariance(
                block_index, candidate_covariance
            )
            candidate_covariance_grid = block_grid
        candidate_block_states = {
            **self._ledger._states_by_block_name,
            block_name: candidate_block_state,
        }
        candidate_signal_sum = self._signal_sum.with_signal(block_index, signal)
        candidate_residual = self._form_residual(candidate_signal_sum.total)
        candidate_block_indices = (
            {**self._block_indices, block_name: block_index}
            if block_to_register is not None
            else self._block_indices
        )
        next_blocks = (
            self._blocks
            if block_to_register is None
            else [*self._blocks, (block_name, block_to_register)]
        )
        candidate_block_domains = (
            self._block_domains
            if block_to_register is None
            else {**self._block_domains, block_name: block_grid}
        )
        candidate_roles = (
            self._roles
            if block_to_register is None
            else {**self._roles, block_name: role}
        )
        next_rng = deepcopy(candidate_rng)

from collections.abc import Sequence
from dataclasses import dataclass, field
from typing import Any

import numpy as np

from enchilada.block import Block

from enchilada.covariance import Covariance

class EchoBlock:
    """Zero-signal diagnostic block that prints residual RMS and advances a counter.

    Register with ``wheel.add(block, role="signal")``: ``initial_sample``
    publishes an empty state, and every ``sample`` call does the same after
    printing. Inspect ``block.state.num_sample_calls`` for the counter;
    diagnostics belong to ``block.state.metadata``. Use a separate instance per
    campaign.
    """

    @dataclass
    class State:
        """Mutable continuation state and diagnostics owned by this block."""

        num_sample_calls: int = 0
        metadata: dict[str, Any] = field(default_factory=dict)

    def __init__(self, name: str):
        self.name = name
        self.state = self.State()

    def initial_sample(
        self,
        conditional_residual: L1Data,
        covariance: Covariance | None,
        *,
        rng: np.random.Generator,
    ) -> BlockState:
        """Publish an empty physical state; the counter and the RNG are untouched."""
        return BlockState()

    def sample(
        self,
        conditional_residual: L1Data,
        covariance: Covariance | None,
        current_block_state: BlockState,
        *,
        rng: np.random.Generator,
    ) -> BlockState:
        """Print the residual RMS, advance the local counter, and publish no signal."""
        first_channel_name = conditional_residual.channel_names[0]
        residual_rms = float(
            np.sqrt(
                np.mean(
                    np.abs(conditional_residual.channel_data[first_channel_name]) ** 2
                )
            )
        )
        num_sample_calls = self.state.num_sample_calls
        print(
            f"[{self.name}] sample {num_sample_calls}: "
            f"residual RMS on {first_channel_name!r} = {residual_rms:.4e}"
        )
        self.state.num_sample_calls += 1
        return BlockState()


def check_block(
    block_under_test: Block,
    observed_data: L1Data,

    *,
    role: Role,
    noise_blocks: Sequence[Block] = (),
    random_seed: int | None = 0,
) -> None:
    """Run a block on a scratch Wheel and validate each returned BlockState.

    Registers each block in ``noise_blocks`` with ``role="noise"``, in order,
    then ``block_under_test`` with ``role``, which calls its ``initial_sample``
    on the observation grid, then calls ``sample`` for ``num_cycles``, passing
    accepted state into each call. Wheel validates the start and every sample
    alike: the signal grid, finiteness, the role's rules and any published
    Covariance.

    Args:
        block_under_test: Configured block whose exchange contract is checked.
            A block that must start at a chosen point is constructed with it.
        observed_data: L1 observations and shared run settings for the scratch run.
        num_cycles: Number of sampling cycles after registration; defaults to 2.
        role: ``"signal"`` or ``"noise"``, the role ``block_under_test`` is
            registered under.
        noise_blocks: Noise blocks registered before ``block_under_test``. A
            signal block that needs a covariance gets it from a
            ``FixedNoiseBlock`` here; a noise block under test receives their
            sum as its ``covariance``.
        random_seed: Seed for the scratch Wheel's NumPy generator, which also
            drives ``initial_sample``. Defaults to 0 for reproducibility; None

"""Edit notebook cells by id, preserving the file's JSON layout."""

import json
import sys
from pathlib import Path


def load(path):
    text = Path(path).read_text()
    nb = json.loads(text)
    # Round-trip guard: these notebooks were written with indent=1, no ASCII
    # escaping and a trailing newline. A mismatch here would reformat the file.
    assert json.dumps(nb, indent=1, ensure_ascii=False) + "\n" == text, path
    return nb


def save(path, nb):
    Path(path).write_text(json.dumps(nb, indent=1, ensure_ascii=False) + "\n")


def cells(nb):
    return {cell["id"]: cell for cell in nb["cells"]}


def set_source(cell, text):
    lines = text.split("\n")
    cell["source"] = [line + "\n" for line in lines[:-1]] + ([lines[-1]] if lines[-1] else [])


def substitute(cell, old, new):
    source = "".join(cell["source"])
    assert source.count(old) == 1, (cell["id"], old, source.count(old))
    set_source(cell, source.replace(old, new))


if __name__ == "__main__":
    for path in sys.argv[1:]:
        load(path)
        print("round-trips:", path)

Create `examples/noise_floor.py`:

```python
"""Two noise blocks: a known floor plus a sampled excess variance on top of it.

The campaign registers two blocks with role="noise". FixedNoiseBlock publishes
the known instrument floor on every call; ExcessNoiseBlock samples an extra
white-noise variance with a Metropolis random walk in log-variance. Wheel hands
the excess block the floor as its `covariance` (the sum over the other noise
blocks) and keeps the campaign covariance equal to floor + excess, which is what
a signal block registered here would receive. Run with:

    uv run --no-sync python examples/noise_floor.py
"""

import numpy as np

from enchilada import BlockState, Covariance, FixedNoiseBlock, L1Data, Wheel

TRUTH = {"floor": 0.25, "excess": 0.75}


class ExcessNoiseBlock:
    """An extra white-noise variance above the covariance this block receives.

    The prior on the variance is log-uniform between `low` and `high`. Each
    `sample` call runs `steps_per_call` Metropolis steps with a Gaussian proposal
    of width `step` in log-variance. The likelihood of the time-domain residual
    uses the total covariance `received + own`, formed with `Covariance.__add__`.
    """

    def __init__(
        self,
        name: str,
        low: float = 1e-3,
        high: float = 1e3,
        step: float = 0.3,
        steps_per_call: int = 10,
    ):
        if not (0 < low < high):
            raise ValueError("the prior needs 0 < low < high")
        self.name = name
        self.low, self.high = low, high
        self.step, self.steps_per_call = step, steps_per_call

    @staticmethod
    def _own(conditional_residual: L1Data, variance: float) -> Covariance:
        if conditional_residual.data_domain != "time":
            raise ValueError("ExcessNoiseBlock requires time-domain data")
        return Covariance.like(
            conditional_residual,
            {
                ch: np.full(conditional_residual.num_time_samples, variance)
                for ch in conditional_residual.channel_names
            },
        )

    def _render(self, conditional_residual: L1Data, variance: float) -> BlockState:
        return BlockState(
            covariance=self._own(conditional_residual, variance),
            parameters={"variance": float(variance)},
        )

    def _log_likelihood(
        self, conditional_residual: L1Data, floor: Covariance, variance: float
    ) -> float:
        total = floor + self._own(conditional_residual, variance)
        value = 0.0
        for ch, residual in conditional_residual.channel_data.items():
            total_variance = total.pair(ch, ch)
            value -= 0.5 * float(
                np.sum(residual**2 / total_variance) + np.sum(np.log(total_variance))
            )
        return value

    @staticmethod
    def _require_floor(covariance: Covariance | None) -> Covariance:
        if covariance is None:
            raise ValueError(
                "ExcessNoiseBlock adds to another noise block's covariance; "
                "register the floor (for instance a FixedNoiseBlock) first"
            )
        return covariance

    def initial_sample(
        self,
        conditional_residual: L1Data,
        covariance: Covariance | None,
        *,
        rng: np.random.Generator,
    ) -> BlockState:
        """Draw the excess variance from its log-uniform prior and publish it."""
        self._require_floor(covariance)
        log_variance = rng.uniform(np.log(self.low), np.log(self.high))
        return self._render(conditional_residual, float(np.exp(log_variance)))

    def sample(
        self,
        conditional_residual: L1Data,
        covariance: Covariance | None,
        current_block_state: BlockState,
        *,
        rng: np.random.Generator,
    ) -> BlockState:
        """Advance a Metropolis random walk in log-variance against the residual."""
        if conditional_residual.data_domain != "time":
            raise ValueError("ExcessNoiseBlock requires time-domain data")
        floor = self._require_floor(covariance)
        log_variance = float(np.log(current_block_state.parameters["variance"]))
        current = self._log_likelihood(
            conditional_residual, floor, float(np.exp(log_variance))
        )
        log_low, log_high = np.log(self.low), np.log(self.high)
        for _ in range(self.steps_per_call):
            proposal = log_variance + self.step * rng.normal()
            if not log_low <= proposal <= log_high:
                continue  # outside the prior: rejected without a likelihood call
            proposed = self._log_likelihood(
                conditional_residual, floor, float(np.exp(proposal))
            )
            if rng.random() < np.exp(min(0.0, proposed - current)):
                log_variance, current = proposal, proposed
        return self._render(conditional_residual, float(np.exp(log_variance)))


def make_observed(seed: int = 0) -> L1Data:
    """Pure white noise whose variance is the floor plus the excess."""
    rng = np.random.default_rng(seed)
    n = 2048
    sigma = np.sqrt(TRUTH["floor"] + TRUTH["excess"])
    return L1Data(
        {"A": rng.normal(0.0, sigma, n)},
        sample_rate_hz=0.1,
        tdi_generation="2.0",
        physical_observable="fractional_frequency",
        start_time_gps=0.0,
    )


def run_example(n_cycles: int = 400, burn_in: int = 100, seed: int = 0) -> dict:
    """Run the campaign; return the excess posterior summary and the Wheel."""
    if not 0 <= burn_in < n_cycles:
        raise ValueError("burn_in must be nonnegative and smaller than n_cycles")
    observed = make_observed(seed)
    campaign_seed = np.random.SeedSequence(seed).spawn(1)[0]
    wheel = Wheel(observed, random_seed=int(campaign_seed.generate_state(1)[0]))
    floor = Covariance.like(
        observed,
        {ch: np.full(observed.N, TRUTH["floor"]) for ch in observed.channel_names},
    )
    # Both are noise blocks. The floor goes first so the excess block's start
    # already receives it; Wheel keeps floor + excess as the campaign covariance.
    wheel.add(FixedNoiseBlock("floor", floor), role="noise")
    wheel.add(ExcessNoiseBlock("excess"), role="noise")
    chain: list[float] = []

    def collect(cycle: int, w: Wheel) -> None:
        chain.append(w.ledger["excess"].parameters["variance"])
        if (cycle + 1) % 100 == 0:
            print(
                f"cycle {cycle + 1:4d}: excess variance draw = {chain[-1]:.4f}  "
                f"(campaign covariance A[0] = {w.covariance.A[0]:.4f})"
            )

    wheel.run(n_cycles, on_cycle_complete=collect)
    samples = np.asarray(chain[burn_in:])
    return {
        "posterior_mean": float(samples.mean()),
        "posterior_std": float(samples.std()),
        "wheel": wheel,
    }


def main() -> None:
    print(f"truth: floor={TRUTH['floor']} (known), excess={TRUTH['excess']}\n")
    result = run_example()
    print()
    print(
        f"excess posterior: {result['posterior_mean']:.4f} +/- "
        f"{result['posterior_std']:.4f}   (truth {TRUTH['excess']})"
    )


if __name__ == "__main__":
    main()
```
